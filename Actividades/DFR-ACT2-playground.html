Vocabulario para leer el diagrama

TablaComo una hoja de Excel: una por cada «cosa» (usuarios, pedidos…). Cada fila es un registro y cada columna, un dato.
PK · clave primariaLa columna que identifica cada fila sin confusión (normalmente id). No se repite.
FK · clave foráneaColumna que apunta a una fila de otra tabla. Ej.: usuario_id en pedidos dice de qué usuario es el pedido.
UQ · únicoEl valor no se puede repetir: dos usuarios no pueden tener el mismo email.

Decisiones de diseño

Libros y revistas en una tabla

Comparten casi todos los datos, así que una columna tipo (libro o revista) los distingue.

Categoría 1:N

Cada publicación en una sola categoría (simple y suficiente). Si quisieras varias, haría falta una tabla intermedia.

precio_unitario en la línea

Si mañana cambia el precio del libro, los pedidos antiguos deben conservar lo que costó entonces.

Cancelar sin borrar

Cancelar una reserva es marcarla como cancelada; así se conserva el histórico.

3 · Diseño de la API REST

Un endpoint por cada necesidad de pantalla. Reglas: recursos en plural (sustantivos), el verbo lo pone el método HTTP, los filtros van en query params y la identidad del recurso en el path.

Vocabulario

API RESTConjunto de direcciones (URLs) a las que la web pide o envía datos.
EndpointCada una de esas direcciones, p. ej. /api/publicaciones.
Método HTTPGET leer · POST crear · DELETE borrar.
Path paramParte de la dirección que identifica algo: /publicaciones/4 (el libro 4).
Query paramFiltros después del ?: ?tipo=libro&anioDesde=2010.
JSONFormato de texto en el que la API devuelve los datos.
Código de estadoNúmero que dice qué pasó: 200 bien, 201 creado, 400 petición mal hecha, 404 no existe, 409 conflicto…

Buenas prácticas que puntúan en el criterio 3

Nombres

/publicaciones sí; /getLibros o /obtener-libros no.

Path vs query

/publicaciones/42 identifica; ?tipo=libro&anioDesde=2010 filtra, ordena y pagina.

Anidado con criterio

/usuarios/1/compras expresa «las compras DE ese usuario». No más de 2 niveles.

Estático antes que dinámico

/publicaciones/mas-vendidos y /publicaciones/[id] conviven: Next prioriza la carpeta estática.

Error uniforme

Siempre { error: { code, message, details } }. El cliente solo necesita un parser.

Paginación

page + limit (con máximo) y meta.total + cabecera X-Total-Count.

4 · Implementar los Route Handlers

Cada carpeta con un route.ts es un endpoint; exportas una función por método HTTP (GET, POST…). Patrón de todos los handlers: validar → llamar a la capa de datos → responder con el código correcto.

Vocabulario

Route HandlerArchivo route.ts de Next.js que responde a una dirección /api/….
Capa de datosFunciones que hacen las consultas SQL, separadas del handler para poder reutilizarlas.
PoolConjunto de conexiones a la base de datos que se reutilizan.
$1, $2…Forma segura de meter valores en una consulta SQL (evita que alguien «inyecte» SQL).
TransacciónVarias operaciones que se hacen todas o ninguna (la compra: crear pedido y bajar stock).
async / awaitEsperar a que la base de datos responda antes de seguir.
