# Visualizar en el navegador

Para ver el archivo HTML en el navegador tienes dos opciones:

**Opción 1 – Live Server** *(recomendado)*
Haz clic derecho sobre el archivo `.html` y selecciona **"Open with Live Server"**.
Se abrirá el navegador y se actualizará automáticamente cada vez que guardes cambios.

**Opción 2 – Abrir directamente**
Haz clic derecho sobre el archivo `.html` y selecciona **"Open in Default Browser"**.
