🧠 Web Storage + Next.js

📘 Concepto

localStorage y sessionStorage son APIs del navegador para almacenar datos en cliente.

⚠️ En Next.js esto es importante:

Next.js ejecuta código en servidor y cliente, pero estas APIs solo existen en el navegador. 

// ❌ Esto falla en Next.js (SSR)
localStorage.getItem("demo");

// ✅ Correcto (solo cliente)
useEffect(() => {
  localStorage.getItem("demo");
}, []);

⚖️ Diferencias clave

  • localStorage: persiste incluso al cerrar navegador
  • sessionStorage: se borra al cerrar pestaña
  • Misma API: setItem / getItem / removeItem

✅ Buenas prácticas

// Serializar datos
localStorage.setItem("user", JSON.stringify(user));

// Recuperar datos
const user = JSON.parse(localStorage.getItem("user"));

// Evitar SSR errors
if (typeof window !== "undefined") {
  localStorage.getItem("demo");
}
  • No guardar datos sensibles
  • Usar JSON para objetos
  • Acceder solo en cliente (Next.js)
